# INTIZOM PRO 8.1 - Android loyiha

Bu **Android SDK bilan APK yaratish uchun to‘liq manba loyiha**. ZIP faylning o‘zi APK emas.

## APK yig‘ish
1. Arxivni oching va **ichidagi fayl/papkalarni** GitHub repo ildiziga joylang (ZIP faylni o‘zini emas).
2. GitHub Actions -> INTIZOM PRO 8.1 - Android APK -> Run workflow.
3. Muvaffaqiyatli tugasa, Artifacts -> INTIZOM-PRO-8.1-APK dan `app-debug.apk` yuklab oling.
4. Telefonda o‘rnating. Telefonning ruxsatlari va ishlab chiqaruvchining batareya cheklovlarini tekshiring.

## Asosiy imkoniyatlar
Odatlar, maqsadlar, fokus, offline eslatmalar, PIN, kitoblar, 4 ta tarif va obuna hamda admin demo.
**Real pul yechish, real admin backend va OpenAI API hali ulanmagan.** Foydalanuvchi uchun PRO xarid qilish tugmasi demo, haqiqiy obuna tasdiqlanmaydi.

## Cheklovlar
Bu muhitda Android SDK mavjud bo‘lmagani sababli APK kompilyatsiyasi va haqiqiy Android telefonda o‘rnatilishi tekshirilmagan. Yig‘ish natijalarini GitHub Actions'dan tekshiring.
